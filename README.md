# Радуга — детский зал в Балашове

Адаптивный сайт детского зала «Радуга» с программами праздников, фотографиями, интерактивным калькулятором и подготовкой заявки.

## Публичная ссылка

После включения GitHub Pages: https://anya-karpova.github.io/raduga-balashov/

Для первой публикации откройте **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save**. После этого GitHub автоматически публикует обновления из main.

## Структура

- `index.html` — разметка сайта;
- `styles.css` — адаптивные стили;
- `script.js` — калькулятор, меню, фильтры, галерея и подготовка заявки;
- `assets/` — оптимизированный фирменный логотип и фотографии.

Для локальной проверки откройте `index.html` в браузере, лучше через небольшой локальный HTTP-сервер.

## Как работает заявка

Сайт **не отправляет персональные данные на сервер** и **не бронирует дату автоматически**. Посетитель выбирает программу, заполняет данные, получает рассчитанный текст заявки и может скопировать его, открыть диалог ВКонтакте или приложение SMS. Отправка сообщения совершается самим посетителем, а дату подтверждает администратор.

Перед публичным использованием необходимо проверить права и согласия на размещение фотографий детей и согласовать правила обработки персональных данных.
